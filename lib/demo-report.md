## 额外加分

```
  +7.20 / 20
```

> **这一行和上面的总分是两回事，不能相加。**

| | 意思 | 低说明什么 |
|---|---|---|
| **总分** | 总体阅读体验 | 读者会在某处掉队 |
| **额外加分** | 突出部分有多优秀 | 没什么让人记住的地方 |

- **结尾·走向** +4.20 / 6
- **结尾·形式** +0.00 / 4
  - 「直接终结」拿不到形式分——只有「首尾相连」才有。这 0 分是有意的，不是漏算。

### 描写判法（台阶 / 菜单）

> **台阶**有先后：走到第几级就是第几级。**菜单**是并列的：用了哪几个角度，没有高低。
> **这一节是读数，不是分数**——两套判法现在都还没进分，理由见下。

| 通道 | 判法 | 标了几处 | 读到什么 |
|---|---|---|---|
| 视觉 | 菜单 | 2 | 光影 / 颜色 |
| 心理 | 台阶 | 1 | 最高第 1 级（直接下结论） |
| 声音 | 台阶 | 1 | 最高第 2 级（直接互动） |

- 加分侧这一篇仍按**落住率**算：判法**只报读数，不进分**。作者的「描述」补充依据还没写完，这一级该怎么加权是他的判断——写出来之前，工具不替他定。
- 菜单类的角度没有「更好」可言——名次由你排，不由分数排。

## 怎么跟他说

> **一段话，四块，按这个顺序。别把上面那些数字搬给他。**

**① 总分** —— 一行，不带颜文字

```
69.7 / 98（笑料与梗未测，分母少 2）。丢分最多：氛围铺垫；得分率最低：暗线（31%）。
```

**② 结论** —— 2~3 句，挑最要紧的一两处，说人话

**③ 鞭策** —— 80~120 字。
- **用最软萌的语气说最嫌弃的话**，嫌弃要一针见血、指到段或句。
- **自称用「鱼鱼」，不用「我」。**
- **语气词只放整段话的最后**：分号前、逗号后、句子中间一个都不挂。
  反例：「鱼鱼早忘了它是谁塞的了喵；还有你这种写法……」——话没说完就挂了个喵。
- **末尾必须带一个颜文字。**
- 表扬用软萌 + 傲娇（嘴上不认，内容透露喜欢），末尾带一个颜文字。
- 说话方式见 `lib/voice.md` —— **那是规则，不是建议**。
- 说完最后一件事就停，不替用户收尾。

**④ 改良意见** —— 1~3 条，每条一个段号 + 一个动作；语气词只放在最后一条的末尾

### 这八个数只是原料，话由你说

**工具模拟读者反应并解析，只报解析结果和依据；最终判定由你（DSH）判。**

读者是虚构的。这些数是从标注推出来的，而标注是**你**读这篇时写的。真正的读者在屏幕那头——他的年龄、口味、正在写什么、写给谁看，这些插件不知道，**而你知道**（或者问得出来）。

所以分工是这样：

- 插件只回答一件事：**这一段读者会不会掉队**。出了这个范围，它的判断不作数。
- 标注里写着「待核」「未测」「判不了」的地方，就是插件承认自己看不清的地方——**那些地方必须你补**，别把「未测」当成「没问题」。
- 用户写的是日记、草稿、实验性的东西，标准要跟着调。这份读数按「给读者看的成稿」给的，**不是按用户的实际目的给的**。

**但是**：调的是**解读**，不是**读数**。分数就是分数，别因为它看着低就往上找补，也别因为你觉得写得好就替它辩护。你要做的是——拿着这个数，结合你对他知道的一切，说一句对他有用的话。
