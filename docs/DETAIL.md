# 灵魂雷达

## 这是什么

一个**模拟读者**。

它不评价文章的好坏，它读一遍，然后报告：读的时候读者身上发生了什么。

- 哪里被抬起来、哪里掉下去
- 哪里卡住了（句子太长、段落装了两三件事）
- 哪里跟不上（情绪在飘，没落到具体的物上）
- 读者会在第几段走神

这些「反应」和「反应的过程」被拆成可数的数据，交给 DSH。**话由 DSH 说，工具只给数据。**

作者对这个工具的定位，原话是：

> 灵魂雷达这个插件相当于模拟了一个读者，并把这个读者阅读时的所有反应和反应的过程都解析为可供你分析的数据，你再用这个数据进行输出。

## 它怎么读

三层，从上往下：

**层1 · 字词句** —— 这句话本身通不通顺、落不落地

**层2 · 意思之间** —— 这几句能不能连上、这一跌有没有台阶

**层3 · 深处** —— 连起来之后，读者感觉到了什么

**再加一层系数** —— 读者接不接得住、读起来累不累

## 两个轴，不能相加

| | 意思 | 低说明什么 |
|---|---|---|
| **总分** | 总体阅读体验 | 读者会在某处掉队 |
| **额外加分** | 突出部分有多优秀 | 没什么让人记住的地方 |

```
分项高 + 额外低   稳，但没有亮点
分项低 + 额外高   有亮点，但整体磕磕绊绊
两项都高          难得
两项都低          重写
```

**为什么不能相加**：「写得稳」和「有亮点」是两件事。加在一起会变成「差不多」，
反而看不出它到底是「稳而无趣」还是「精彩但粗糙」。

## 描写：两把尺子

同一种「情感落到物上」，判法不一样：

```
台阶  声音  拟声词 → 直接互动 → 细节+比喻
      心理  直接下结论 → 生理反应 → 潜意识错觉（第三级可选）
菜单  视觉  颜色 / 光影 / 主观感受   ← 并列，「第三级不一定更好」
特殊  音乐  命名曲名 / 大幅旁敲侧击   ← 时间→空间翻译不了
```

**台阶有先后，菜单只有情况。**

工具现在把两种都**读出来**：

| | 读什么 | 台阶类 | 菜单类 |
|---|---|---|---|
| 扣分侧 | 落没落住 | 照旧 | 照旧 |
| 加分侧 | 还没用它 | 只报最高到第几级 | 只报用了哪几个角度，不排名次 |

**两套判法都还没进分**——「描述」的补充依据还没写完，这一级该怎么加权由作者定。

给菜单类写级数会被拒收——那不是在报一个低分，是在报一个不存在的维度。

## 它也算不清的时候

某条判据样本太少、标注没给、或者工具本身看不见——报告里写「未测」，**不进分母**。

```
一篇 88 段的短篇   77.90 / 100.00
猫猫庙           74.33 /  88.00   ← 逻辑未标，分母少 12
```

**不同文章的分数不能直接横比。** 要比，先看分母。

一条工具的自我认知比它的准确率更重要：**说「我看不见」比假装看得见有用。**

## 判据从哪来

每条判据都能追到三个来源之一：

1. **理论文件里的原话**（`lt_rules` 会给出依据）
2. **作者对实测结果的纠正**
3. **实现者的判断**——这种情况下备注里会明写「这是我定的，作者还没给」

判据表当前 **49 条：定稿 41、待建 1、已推翻 6**。

已推翻的 6 条也留着记录和理由——「为什么不要这条」和「为什么要这条」一样有价值。

## 它刻意不做的事

- 不给文学评价。它量的是「读者会不会掉队」，不是「写得好不好」
- 不替 DSH 说话。报告是数据包
- 不改文章。只读
